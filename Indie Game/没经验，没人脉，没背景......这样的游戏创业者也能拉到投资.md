# TLDR

在游戏投资领域，投资方最看重的是团队的热情、专业能力、产品的独特性以及创始人的眼界与执行力，而非单纯的经验、人脉或背景。 所谓的“三无”创业者，只要方法得当、产品够好，完全有机会获得投资。

# 核心思想总结

“投人”重于“投事”：三位嘉宾反复强调，早期项目主要看团队，尤其是创始人的特质（真诚、狂热、有管理能力、有愿景）。产品可以调整，但团队的内核决定了公司的天花板。

产品为王，亮点先行：在有限时间内，必须用demo或可玩切片快速展示产品的独特亮点（差异化），而不是按部就班讲新手引导。投资人寻找的是“念念不忘”的感觉。

自信与开放比学历背景更重要：没有大厂背景的新人，可以通过参赛、参展、发社交媒体、找老前辈引荐等方式触达投资人。见面时不卑不亢，在专业领域要敢于坚持自己的判断。

估值合理，关注IP化潜力：估值不是越高越好，单机游戏的价值不仅在于销量，更在于未来IP化的可能性。创业者应通过竞品分析给出合理的预期，而非漫天要价。

分歧处理与信任建立：业务分歧时投资人会尊重创业者的专业判断；金融条款分歧则应听从有经验的投资方。靠谱的机构看重长期声誉，合作前把细节谈透比盲目信任更重要。

# 给“三无”创业者的切实路径

| 困境 | 专家的解决路径 |
| :--- | :--- |
| **没经验** | 1. 做出**完整可玩的demo或精致切片**，让产品说话<br>2. 参加GWB等大赛，获奖是直接背书<br>3. 展示超出年龄的**行业见解或技术亮点** |
| **没人脉** | 1. 通过**社交媒体（B站、微博）、大赛、展会**主动展示<br>2. 利用**校友、前同事资源**，找已成功的老创业者引荐<br>3. 直接给投资机构邮箱发邮件，不要怕被忽视 |
| **没背景** | 1. 面试投资机构：查官网、投过项目、媒体报道，选大机构更靠谱<br>2. **自信**：在专业领域说服投资人，不卑不亢<br>3. 谈协议时**把细节落到位**（分几批打钱、什么时间），避免后续分歧 |

# 结论

这篇访谈传递给游戏创业者的核心信息是——忘掉“三无”的自卑，专注于点燃内心的火、打磨产品的魂，并用专业和自信去说服认可“长期主义”的投资人。 投资方寻找的不是完美的履历，而是那些“没有人能阻挡他去实现梦想”的团队。
